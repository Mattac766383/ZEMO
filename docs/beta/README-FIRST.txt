ZEMO — Bêta privée macOS
========================

Apple Silicon uniquement (M1 et suivants). Pas Intel.

Installation
------------
1. Ouvrez le fichier DMG.
2. Glissez ZEMO dans Applications.
3. Ouvrez Applications.
4. Faites clic droit sur ZEMO → Ouvrir.
5. Confirmez Ouvrir si macOS affiche un avertissement.

Ne désactivez pas Gatekeeper. Ne lancez pas de commande sudo pour contourner macOS.

Pour les premiers essais
------------------------
Utilisez un dossier contenant des copies de fichiers non importants.

ZEMO fonctionne localement sur votre ordinateur.
Les fichiers ne sont déplacés que si vous cliquez « Appliquer l’organisation ».
Vous pouvez ensuite « Annuler les changements » lorsque c’est encore possible.
